## Português (Brasil)

Um player de audiolivro feito com React para ouvir capítulos de **Memórias Póstumas de Brás Cubas**, de Machado de Assis. A interface reúne a capa do livro, a seleção do capítulo, a barra de progresso e controles de reprodução.

### Funcionalidades

- Reproduzir e pausar o áudio;
- avançar ou voltar 15 segundos;
- navegar para o capítulo anterior ou seguinte, com navegação circular;
- acompanhar o progresso e pular para outro ponto do áudio.

### Tecnologias

- [React](https://react.dev/) 19;
- [Vite](https://vite.dev/) 7 para desenvolvimento e build;
- HTML Audio API para reprodução dos capítulos;
- [Bootstrap Icons](https://icons.getbootstrap.com/) para ícones;
- ESLint para análise estática do código.

### Executar localmente

Requer Node.js e npm.

1. Instale as dependências com `npm install`.
2. Inicie o servidor de desenvolvimento com `npm run dev`.
3. Abra no navegador o endereço exibido pelo Vite.

Para validar o código, execute `npm run lint`. Para gerar a versão de produção, execute `npm run build`; o resultado será salvo em `dist/`.

### Áudio e domínio público

Os arquivos de áudio utilizados neste projeto são gravações do **LibriVox**, uma iniciativa de voluntários que disponibiliza audiolivros de obras em domínio público. O texto de _Memórias Póstumas de Brás Cubas_ também é de domínio público. As gravações do LibriVox são consideradas de domínio público nos Estados Unidos; como as regras podem variar conforme o país e a gravação, consulte a página da edição específica e a legislação local antes de reutilizar ou redistribuir os arquivos.

Saiba mais em [LibriVox](https://librivox.org/).

## English

A React audiobook player for listening to chapters of **The Posthumous Memoirs of Brás Cubas** by Machado de Assis. The interface brings together the book cover, chapter selection, playback progress, and audio controls.

### Features

- Play and pause audio;
- skip forward or backward by 15 seconds;
- move to the previous or next chapter, with circular navigation;
- track playback progress and seek to another point in the audio.

### Technologies

- [React](https://react.dev/) 19;
- [Vite](https://vite.dev/) 7 for development and production builds;
- HTML Audio API for chapter playback;
- [Bootstrap Icons](https://icons.getbootstrap.com/) for icons;
- ESLint for static code analysis.

### Run locally

Node.js and npm are required.

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the URL printed by Vite in your browser.

Run `npm run lint` to check the code. Run `npm run build` to create a production build in `dist/`.

### Audio and public domain

The audio files used in this project are recordings from **LibriVox**, a volunteer initiative that provides audiobooks of public-domain works. The text of _The Posthumous Memoirs of Brás Cubas_ is also in the public domain. LibriVox recordings are considered public domain in the United States; rules may vary by country and recording, so check the specific edition’s page and local law before reusing or redistributing the files.

Learn more at [LibriVox](https://librivox.org/).
